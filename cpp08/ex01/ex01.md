# Exercise 01 — Span

## Goal

Build a `Span` class that holds up to `N` integers and can compute two metrics over its stored values:

- **Shortest span** — the smallest absolute difference between any two stored numbers
- **Longest span** — the difference between the maximum and minimum stored numbers

The class must also support bulk-insertion via an iterator range.

---

## Concepts Covered

### Orthodox Canonical Form
The class provides all four special member functions: default constructor (deleted — only the `unsigned int N` constructor is meaningful), copy constructor, copy assignment operator, and destructor. The `_numbers` vector handles its own memory, so the destructor is trivial.

### `std::vector` as Internal Storage
`std::vector<int>` is the natural choice: it grows dynamically, supports `push_back`, and exposes full random-access iterators needed by `std::sort` and `std::min/max_element`.

### Shortest Span Algorithm
The naive O(n²) approach compares every pair. The STL-idiomatic O(n log n) approach:
1. Copy the numbers into a sorted vector (`std::sort`).
2. Apply `std::adjacent_difference` (from `<numeric>`) to produce an array where `diffs[i] = sorted[i] - sorted[i-1]`.
3. Return `*std::min_element(diffs.begin() + 1, diffs.end())`.

The smallest gap between any two numbers must appear between two adjacent elements in the sorted order.

### Longest Span Algorithm
`*std::max_element(...) - *std::min_element(...)` — two linear passes, clean and idiomatic.

### Iterator-Range Bulk Insertion
```cpp
template <typename InputIterator>
void addNumbers(InputIterator begin, InputIterator end);
```
Because this is a template, it must be defined in the header file. The implementation:
1. Computes the distance with `std::distance`.
2. Checks capacity before inserting (throws if not enough room).
3. Uses `_numbers.insert(_numbers.end(), begin, end)` — one call that maps directly to `std::vector::insert(pos, first, last)`.

This mirrors how `std::vector::assign` and `std::vector::insert` accept iterator ranges, which is the idiom the subject hints at.

## Exception Strategy

| Situation | Exception message |
|---|---|
| `addNumber` called on a full Span | `"Span is full"` |
| `addNumbers` would exceed capacity | `"Not enough capacity to add all numbers"` |
| `shortestSpan`/`longestSpan` with < 2 elements | `"Not enough numbers to find a span"` |

All exceptions derive from `std::exception` and are thrown as `std::runtime_error`.
