# Exercise 01 — Iter

## What it is

Implement a single function template `iter` that applies a function to every element
of an array:

```cpp
template <typename T, typename F>
void iter(T *array, std::size_t len, F func);
```

## Key concepts

### Two template parameters

`T` is the element type, `F` is the callable type. Keeping `F` as its own template
parameter is the cleanest approach: it accepts any callable (function pointer,
function template instantiation, functor) without forcing a specific signature.

### const vs non-const arrays

The subject explicitly warns to support both. The solution is two overloads:

```cpp
template <typename T, typename F>
void iter(T *array, std::size_t len, F func);          // non-const elements

template <typename T, typename F>
void iter(T const *array, std::size_t len, F func);    // const elements
```

Without the const overload, passing a `const int[]` would fail to compile because
the compiler cannot bind a `const int *` to `T *` without dropping the qualifier.

### Third parameter as instantiated function template

The subject says the third argument *can* be an instantiated function template,
meaning you can write:

```cpp
void print(int const &x) { std::cout << x << std::endl; }
iter(arr, 5, print);          // plain function pointer
iter(arr, 5, print<int>);     // explicit instantiation also legal
```

Both work because `F` is deduced from the argument.
