# Exercise 02 — Array

## What it is

Implement a class template `Array<T>` — a safe, heap-allocated, bounds-checked
array that follows the Orthodox Canonical Form.

## Required interface

| Feature | Notes |
|---|---|
| `Array()` | Default constructor — empty array (`_size = 0`, `_data = NULL`) |
| `Array(unsigned int n)` | Allocates `n` default-initialised elements via `new T[n]()` |
| `Array(Array const &)` | Deep copy — independent memory |
| `operator=(Array const &)` | Deep copy assignment — must handle self-assignment |
| `~Array()` | `delete[]` the data |
| `T &operator[](unsigned int i)` | Bounds-checked access; throws `std::exception` if out of range |
| `T const &operator[](unsigned int i) const` | Const overload |
| `unsigned int size() const` | Returns `_size` |

## Key concepts

### `new T[n]()` — value-initialisation

The `()` at the end value-initialises the elements. For primitives (`int`, `double`)
this zero-initialises them. For class types it calls their default constructor.
Without `()` the elements would be uninitialised for primitives.

### Deep copy

The copy constructor and assignment operator must allocate new memory and copy
each element individually — not just copy the pointer. Otherwise the two `Array`
objects would share the same buffer, and destroying one would corrupt the other.

### Self-assignment guard

In `operator=`, always check `if (this != &rhs)` before freeing and reallocating.
Failing to do so would delete `_data` before reading from `rhs._data` (same object).

### Why `std::exception` and not a custom one?

The subject says "an `std::exception` is thrown" without specifying which derived
type. Using `std::out_of_range` (a subclass of `std::exception`) is the most
semantically appropriate choice and fully satisfies the requirement.

### Template implementation in headers / .tpp

Because the compiler needs the full template definition to instantiate it,
everything lives in `Array.hpp`. Alternatively, a `.tpp` file can be written and
`#include`d at the bottom of the header — both approaches are valid and the subject
explicitly lists `Array.tpp` as an optional file.
