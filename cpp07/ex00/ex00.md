# Exercise 00 — Start with a few functions

## What it is

Implement three function templates in a header file:

- `swap(T &a, T &b)` — exchanges the values of two variables, returns nothing
- `min(T const &a, T const &b)` — returns the smaller of two values; returns the second if equal
- `max(T const &a, T const &b)` — returns the greater of two values; returns the second if equal

## Key concept: function templates

A function template lets the compiler generate a type-specific version of a function
at the call site. The syntax is:

```cpp
template <typename T>
T min(T const &a, T const &b) {
    return (b < a) ? b : a;
}
```

When you write `::min(2, 3)` the compiler instantiates `min<int>` automatically.
When you write `::min(std::string("a"), std::string("b"))` it instantiates `min<std::string>`.

The `::` scope resolution prefix is required in the subject's test to avoid
ambiguity with `std::min` / `std::max` which are in the global-ish `std` namespace.

## Why templates must live in header files

The compiler needs the full template definition at every instantiation point (each
`.cpp` file that uses it). Putting the definition in a `.cpp` would make it invisible
to other translation units, causing linker errors. This is the one explicit exception
the general rules mention: *"Any function implementation put in a header file
(except for function templates) means 0."*

## Equal-values rule

Both `min` and `max` return the **second** argument when the two values compare equal.
Implementation: use `<` only, never `<=`:

```
min: return (b < a) ? b : a;   // if a==b, condition false → return a  ← WRONG
                                // subject says return second (b)
     return (a < b) ? a : b;   // if a==b, condition false → return b  ← CORRECT
max: return (a < b) ? b : a;   // if a==b, condition false → return a  ← WRONG
     return (b < a) ? a : b;   // if a==b, condition false → return b  ← CORRECT
```
