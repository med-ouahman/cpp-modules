# Exercise 01 — Serialization

## What it is

Implement a `Serializer` class (non-instantiable) with two static methods:

- `serialize(Data*)` — converts a pointer to `uintptr_t`
- `deserialize(uintptr_t)` — converts a `uintptr_t` back to `Data*`

The round-trip must be lossless: `deserialize(serialize(ptr)) == ptr`.

## Cast used: `reinterpret_cast`

`reinterpret_cast` is the only C++ cast that can legally convert between a pointer
and an integer type. `static_cast` will refuse to compile this conversion.
`uintptr_t` (from `<stdint.h>`) is guaranteed to be wide enough to hold any pointer
on the platform, making the round-trip safe.

```cpp
uintptr_t raw = reinterpret_cast<uintptr_t>(ptr);
Data *back    = reinterpret_cast<Data *>(raw);
```

This is the canonical "serialize a pointer" pattern — storing an address as an
integer so it can be passed through an integer channel and recovered later.

## Why this matters

In systems programming (IPC, messaging, embedded), you sometimes need to pack a
pointer into a fixed-width integer field (e.g. a message queue payload, a file
descriptor context). `reinterpret_cast` with `uintptr_t` is the standard C++ way.
