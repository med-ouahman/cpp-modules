# Exercise 00 — Conversion of Scalar Types

## What it is

Build a `ScalarConverter` class with a single static method `convert(std::string)` that:

1. Detects the literal type of the input string (char, int, float, double, or a pseudo-literal)
2. Converts it to its actual C++ type
3. Explicitly casts it to all four scalar types and prints each result

The class must not be instantiable (private constructor + no copy/assignment).

## Cast used: `static_cast`

`static_cast<T>(value)` performs compile-time checked conversions between related
numeric types. It is the right tool here because:
- All conversions are between fundamental arithmetic types (char / int / float / double)
- There is no polymorphism or pointer reinterpretation involved
- The conversions are semantically meaningful and checked at compile time

## Detection logic

| Pattern | Detected type |
|---|---|
| `'x'` (single char in quotes) | char |
| `-inff`, `+inff`, `nanf` | float pseudo-literal |
| `-inf`, `+inf`, `nan` | double pseudo-literal |
| Ends with `f`, contains `.` or digits | float |
| Contains `.` (no trailing `f`) | double |
| All digits (optional leading `-`) | int |

## Edge cases

- **char 0**: ASCII 0 is not displayable → print `Non displayable`
- **nan/inf → char/int**: mathematically impossible → print `impossible`
- **Overflow**: value outside `INT_MIN`/`INT_MAX` → int is `impossible`
- **Float precision**: always print at least one decimal place (`42.0f` not `42f`)

## Output format

```
char: 'A'          (or: Non displayable / impossible)
int: 42            (or: impossible)
float: 42.0f       (or: nanf / -inff / +inff / impossible)
double: 42.0       (or: nan / -inf / +inf / impossible)
```
